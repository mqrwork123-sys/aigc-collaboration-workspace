# AIGC课程教育：项目上下文

## 项目目标

本项目用于制作和迭代“未来导演计划”相关的 AIGC 课程介绍、课程地图、课程定位页、会议纪要与配套视觉材料。

## 工作方式

- 修改前先确认用户要改的是哪一个具体 HTML、演示素材或文档；不要用一个草稿覆盖其他版本。
- 优先直接完成可交付文件中的修改，并在完成后说明改动了哪个文件。
- 用户通常不会自行调整 CSS 或 XML。若需要用户手动替换内容，提供完整、可直接替换的区块，而非仅给零散 CSS 片段。
- 在要求保留既有结构、类名或 `data-note` 引文约束时，必须保留这些约束。
- 视觉与文字修改应保持课程教育场景下的清晰、专业、可展示性；不要删改既有素材，除非用户明确要求。

## 同步习惯

- 开始工作前先检查 Git 状态并拉取远程最新版本。
- 完成一批用户请求后提交并推送，提交说明用中文概括实际改动。
- 不提交密钥、证书或本机临时文件。
